Proyecto: Monitoreo de Cadena de Frío

Sistema embebido basado en ESP32 para monitoreo y registro
continuo de temperatura mediante sensores DS18B20.

El sistema registra datos en una tarjeta MicroSD
y genera alertas visuales y sonoras cuando se detectan
condiciones fuera del rango permitido.

Componentes:

- ESP32 DevKit V1
- 2 sensores DS18B20
- Módulo MicroSD
- LED Verde
- LED Rojo
- Buzzer Piezoeléctrico

Aplicaciones:

- Vacunas
- Medicamentos
- Reactivos químicos
- Productos perecederos
